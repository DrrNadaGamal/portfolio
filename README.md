# Nada Gamal — Portfolio

Personal portfolio of Nada Gamal, a web developer focused on WordPress (Elementor, Bricks), PHP, and custom front-end work.

Live preview: https://portfolio-nada-software-dev.vercel.app

## Contents

- `index.html` — single-page portfolio (projects, about, contact)
- `projects/` — individual project case-study pages
- `demos/` — runnable front-end demos (Northwind, NovaLearn, HabitFlow, NG Studio)
- `assets/` — shared CSS/JS and images

ContentPilot runs as its own hosted demo: https://contentpilot-rho.vercel.app (source: https://github.com/DrrNadaGamal/contentpilot).

Static site, no build step. Deployed on Vercel.
