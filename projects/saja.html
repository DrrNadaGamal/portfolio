The problem

Keep an assistant’s tool loop small, bounded and easy to inspect.

What was built

A provider interface, tool-call loop, calculator, current-time tool and persistent notes.

The approach

Keep the loop inspectable, bound tool steps, and test offline with a scripted provider. Arithmetic uses an allowed syntax tree rather than eval.

The result

A Python command-line core includes a provider interface, calculator, notes and a bounded tool loop. It is not a connected assistant service.

Evidence & production limits

CLI source delivered previously. No invented graphical interface or live messaging integration is shown.

This is an assistant core, not a full personal-assistant service. WhatsApp, web search, calendar access and streaming are future work. Any examples or demonstration data are synthetic; they do not represent real users, client records, revenue or measured business outcomes.
